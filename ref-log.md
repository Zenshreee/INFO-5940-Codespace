What did you learn from implementing a multi-agent workflow?

    I learned a lot from imeplementing a multi-agent workflow. Specifically, I learned how to construct informative and useful system prompts for the agents to understand their role. I knew that I need to be extra specific on the instructions for the agents to have the right intent and output. I also was able to learn more about Tavily and how the internet search tool works which was interesting to see. Some things that were helpful throughout this process was the instructions for the assignment. They provided a lot of guidance and helped me draft the prompts.

Challenges faced and how you addressed them.

    The main challenge I faced was getting the agents to output the correct format. The way I addressed this was using formatted prompts for the agents to better understand. Earlier I was using a large paragraph of text for the instructions which was not effective. There was a minor challenge in setting up the Tavily API key and getting the API key to work with the agents. This was a minor environment bug that I had to fix by reinstalling packages.

Any creative ideas, variations, or design choices (e.g., persona roles, prompt design).

    One design choice I made was to have the reviewer also output an updated itinerary based on the fixes and suggestions it produces. This was to make it easier for the user to understand the changes and see the improvements. I made sure all agents were very precise in their plan and made sure the reviewer was intentional in looking at the feasibility of the plan.

Note any external tools or GenAI assistance used and why.

    I used GenAI assistance to help me with organizing necessary information for the agents. I used ChatGPT to help me with deciding what information should be provided to the agents in order to have the correct output. I thought that this was helpful because AI is very good at extracting whats important and relvant to the task at hand. This is why i decided to use it.
